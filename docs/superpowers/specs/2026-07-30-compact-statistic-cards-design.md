# 紧凑统计卡片界面设计

## 目标

缩短“全部岗位、已投递、面试进行中、已有 Offer”标题与数字之间的距离，
让统计区成为紧凑、清晰的四列卡片，并把主要窗口空间留给岗位表格或空状态。

本次仅调整界面布局和样式，应用版本继续保持 `v1.1.0`，不创建新的 GitHub
Release，也不修改数据库结构、数据目录或更新逻辑。

## 当前问题

- `StatisticCard` 没有限制纵向尺寸，父布局在表格隐藏时会把统计卡片拉高。
- 卡片内部的垂直布局会在过高区域中分配多余空间，导致标题与数字相距很远。
- 样式表使用 `QLabel[card="true"]`，实际设置 `card` 属性的控件是
  `QWidget`，因此白色背景、边框和圆角没有应用到统计卡片。

## 设计

- 继续使用横向四列、等宽的统计卡片，不改变统计数据或字段名称。
- 每张卡片采用固定纵向尺寸，目标高度约 `90px`；横向仍可随窗口宽度伸展。
- 卡片内部边距约为左右 `16px`、上下 `12px`，标题与数字间距约 `4px`。
- 标题使用较弱的蓝灰色；数字保持深蓝色、粗体和醒目的字号。
- 卡片使用白色背景、浅灰蓝边框与 `8px` 圆角。
- 统计卡片行与下方表格或空状态之间保留约 `14px` 间距。
- 修正样式选择器，使其匹配实际的 `QWidget[card="true"]`。

## 行为与兼容性

- 窗口缩放时四张卡片保持等宽横排；现有最小窗口宽度足以容纳四张卡片。
- 刷新、筛选、统计值更新和“检查更新”等现有功能保持不变。
- 本地重新打包时继续使用当前数据目录，现有台账记录不会被覆盖。

## 验证

- 新增界面测试，断言统计卡片采用固定高度策略并具有紧凑的最大高度。
- 新增样式测试，断言卡片选择器匹配 `QWidget[card="true"]`。
- 运行完整测试套件。
- 在离屏环境渲染主窗口截图，检查标题和数字间距、四卡片等宽及下方内容空间。
- 重新打包并使用本地同步脚本更新稳定安装目录，不发布新版本。
