# Windows 便携 ZIP 分发包设计

## 目标

为“秋招进程台账”生成一个适用于 Windows 10/11 64 位系统的便携 ZIP 分发包。接收者不需要安装 Python，解压后双击 `秋招进程台账.exe` 即可运行。

## 分发形式

- 输出文件名：`秋招进程台账-Windows-x64.zip`
- ZIP 根目录包含一个 `秋招进程台账` 文件夹。
- 文件夹内包含主程序 `秋招进程台账.exe` 和 PyInstaller `onedir` 模式所需的 `_internal` 运行时目录。
- 不创建安装程序，不写注册表，不要求管理员权限。
- 不把 `build` 中间产物作为分发内容。

## 本地数据与隐私

- 发布包不包含开发者的数据库、日志、备份、导出文件或其他个人数据。
- 程序继续通过 `QStandardPaths.AppDataLocation` 获取当前 Windows 用户的本地应用数据目录。
- 每位接收者首次运行时，在自己的电脑和 Windows 用户账户下创建独立数据库。
- 后续再次启动时读取同一份本地数据库，从而保留台账“记忆”。
- 删除或替换程序目录不会主动删除用户数据；不同电脑之间不会自动同步数据。

## 构建策略

- 使用项目虚拟环境及现有 PyInstaller `onedir`、`windowed` 配置进行干净构建。
- 仅在有验证证据的前提下排除未使用的依赖，避免为了缩小体积破坏 PySide6 运行时。
- 对发布目录进行 ZIP 压缩，使对外发送时只有一个文件。
- 用户必须完整解压后运行 EXE，不能只从 ZIP 中单独拖出 EXE。

## 验证标准

1. 完整运行 `python -m pytest -q`，所有测试通过。
2. 从新生成的发布目录启动 EXE，确认主窗口出现且进程保持响应。
3. 在隔离的临时本地应用数据目录中启动程序，确认数据库能够创建并在再次启动时复用。
4. 检查 ZIP 文件清单，确认不存在 `.db`、日志、备份、缓存、源码、测试文件和 `build` 中间文件。
5. 解压 ZIP 到包含中文和空格的临时路径，再次启动 EXE。
6. 记录最终压缩包大小及 SHA-256 校验值。

## 交付物

- `秋招进程台账-Windows-x64.zip`
- 一份简短使用说明，说明“完整解压后运行 EXE”以及本地数据保存行为。
- ZIP 的 SHA-256 校验值。

## 非目标

- 不制作 MSI、安装向导或自动更新功能。
- 不提供云同步、账号登录或跨电脑共享数据库。
- 不携带开发者现有台账数据。
- 不以牺牲可启动性为代价追求单文件 EXE 或极限压缩。
